# 음성(TTS) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 단어·예문·가나는 Azure로 미리 만든 여성 음성 mp3로, 대화 문장은 브라우저 음성으로 [듣기]·[천천히 듣기]를 제공하고, 정적 `/settings` 화면을 만든다.

**Architecture:** 순수 함수(`src/lib/audio.ts`)가 파일 경로·SSML·브라우저 음성 고르기를 정한다. 로컬 스크립트(`scripts/generate-audio.ts`)가 Azure REST로 mp3를 만들어 `public/audio/female/`과 `data/audio-manifest.json`에 쓰고 커밋한다. 화면은 공용 `SpeakButtons`(파일은 `Audio`, 대화는 `speechSynthesis`)를 카드·빈칸·가나·대화에 붙인다. 서버·DB·API는 바꾸지 않는다.

**Tech Stack:** Next.js 16.3.8(App Router), React 19.2.8, TypeScript strict, Tailwind, lucide-react 1.52.0, Vitest 5(jsdom), tsx, Azure Speech REST(F0)

**Spec:** `docs/spec/audio.md`(기준), `docs/spec/ui.md` "음성 재생"·"/settings"·화면별 구성, `docs/spec/testing.md`, ADR-014

## Global Constraints

- 파일 경로: 단어 `/audio/female/words/{word_id}.mp3`, 예문 `/audio/female/words/{word_id}-ex.mp3`, 가나 `/audio/female/kana/{히라가나 코드포인트 16진수 소문자}.mp3`(가타카나는 코드포인트 − 0x60인 히라가나 파일)
- Azure: 음성 `en-US-AvaNeural`·`ja-JP-NanamiNeural`, 형식 `audio-24khz-48kbitrate-mono-mp3`, 엔드포인트 `https://{region}.tts.speech.microsoft.com/cognitiveservices/v1`, 요청 간격 3초 이상(F0 분당 20회), 429는 `Retry-After`(없으면 60초) 뒤 같은 항목 재요청, 그 밖의 오류·빈 응답은 멈춤
- 키는 `.env.local`의 `AZURE_SPEECH_KEY`·`AZURE_SPEECH_REGION`만 쓴다. `NEXT_PUBLIC_`을 붙이지 않고, 키 값을 출력하지 않는다(길이만 확인).
- 천천히 듣기 속도 `0.75`(파일 `playbackRate`, 브라우저 음성 `rate`)
- 문구(그대로): "듣기", "천천히 듣기", "소리를 재생하지 못했어요. 다시 눌러 보세요.", "발음은 합성 음성이에요.", "대화 문장은 기기의 음성으로 읽어요.", "준비 중이에요", "영어 Ava · 일본어 Nanami"
- `src/lib/`는 순수 함수만(I/O·환경변수·fetch 없음). 구현 파일 경로에 `test` 문자열을 넣지 않는다.
- TDD guard: `page.tsx`/`layout.tsx`를 뺀 모든 `.ts(x)`에 같은 폴더의 `*.test.ts(x)`가 먼저 있어야 한다. hook 통과용 빈 테스트를 만들지 않는다.
- `dangerouslySetInnerHTML`을 쓰지 않는다. UI는 `@theme` 토큰 클래스만, 이모지 없이 lucide 아이콘(`Volume2`, `Snail`, `Settings`, `CircleAlert`)을 쓴다. 에러는 토스트로 띄우지 않는다.
- 커밋은 conventional commits + 마지막 줄 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. 커밋 전에 `git status -sb`로 브랜치(`feat-tts`)와 남의 변경을 확인한다. Task 3이 생성 중인 `public/audio/`·`data/audio-manifest.json`은 Task 3 커밋에서만 `git add`한다(다른 Task에서 `git add -A` 금지).

```ts
import { parseFurigana } from "./furigana";
import { KANA } from "./kana";
import type { Language } from "./levels";

// 음성 파일 경로와 읽을 내용(spec/audio.md). 생성 스크립트와 화면이 같이 쓴다.
// 지금은 여성 음성만 만든다. 남성 음성은 나중에 "male" 폴더로 같은 구조를 추가한다
const VOICE_DIR = "female";

export const SLOW_RATE = 0.75;

// Azure SSML의 xml:lang이자 브라우저 음성을 고를 때 먼저 찾는 locale
export const SPEECH_LOCALE: Record<Language, string> = { en: "en-US", ja: "ja-JP" };

export function wordAudioPath(wordId: string): string {
  return `/audio/${VOICE_DIR}/words/${wordId}.mp3`;
}

export function exampleAudioPath(wordId: string): string {
  return `/audio/${VOICE_DIR}/words/${wordId}-ex.mp3`;
}

const KATAKANA_FIRST = 0x30a1; // ァ
const KATAKANA_LAST = 0x30f6; // ヶ
const KATAKANA_TO_HIRAGANA = 0x60; // ア(30A2) − あ(3042)

// 가타카나는 소리가 같은 히라가나 파일을 쓴다
export function kanaAudioPath(char: string): string {
  const code = char.codePointAt(0) ?? 0;
  const hiragana = code >= KATAKANA_FIRST && code <= KATAKANA_LAST ? code - KATAKANA_TO_HIRAGANA : code;
  return `/audio/${VOICE_DIR}/kana/${hiragana.toString(16)}.mp3`;
}

export function escapeXml(text: string): string {
  return text
    .replace(/&/g, "&amp;")
    .replace(/</g, "&lt;")
    .replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;")
    .replace(/'/g, "&apos;");
}

export type SpeechWord = { id: string; language: Language; word: string; reading: string | null; example: string };

const HAN = /\p{Script=Han}/u;
const BLANK_MARKS = /\{\{|\}\}/g;

function sub(text: string, alias: string): string {
  return `<sub alias="${escapeXml(alias)}">${escapeXml(text)}</sub>`;
}

// 일본어는 데이터의 읽기를 <sub alias>로 넘겨 한자를 잘못 읽지 않게 한다
export function wordSpeech(w: SpeechWord): string {
  if (w.language === "ja" && w.reading !== null && w.reading !== w.word && HAN.test(w.word)) return sub(w.word, w.reading);
  return escapeXml(w.word);
}

export function exampleSpeech(w: SpeechWord): string {
  const sentence = w.example.replace(BLANK_MARKS, "");
  if (w.language !== "ja") return escapeXml(sentence);
  return parseFurigana(sentence)
    .map((s) => (s.reading === undefined ? escapeXml(s.text) : sub(s.text, s.reading)))
    .join("");
}

export function ssmlDocument(language: Language, voiceName: string, body: string): string {
  return `<speak version="1.0" xmlns="http://www.w3.org/2001/10/synthesis" xml:lang="${SPEECH_LOCALE[language]}"><voice name="${voiceName}">${body}</voice></speak>`;
}

export type AudioItem = { path: string; source: string; language: Language; body: string };

// 만들 음성 목록: 단어마다 단어·예문, 그리고 히라가나 71자(가타카나는 같은 파일을 쓴다)
export function audioItems(words: readonly SpeechWord[]): AudioItem[] {
  const fromWords = words.flatMap((w) => [
    { path: wordAudioPath(w.id), source: w.id, language: w.language, body: wordSpeech(w) },
    { path: exampleAudioPath(w.id), source: w.id, language: w.language, body: exampleSpeech(w) },
  ]);
  const fromKana = KANA.hiragana.map((k) => ({
    path: kanaAudioPath(k.char),
    source: k.char,
    language: "ja" as const,
    body: escapeXml(k.char),
  }));
  return [...fromWords, ...fromKana];
}

// 브라우저 음성: locale이 같은 것(- _ 구분 없이) → 언어가 같은 첫 음성 → 없음.
// 기본 음성으로 대신 읽으면 일본어를 영어 음성으로 읽게 되므로 없으면 null이다
export function pickVoice<T extends { lang: string }>(voices: readonly T[], language: Language): T | null {
  const norm = (lang: string) => lang.replace("_", "-").toLowerCase();
  const locale = SPEECH_LOCALE[language].toLowerCase();
  return (
    voices.find((v) => norm(v.lang) === locale) ??
    voices.find((v) => norm(v.lang) === language || norm(v.lang).startsWith(`${language}-`)) ??
    null
  );
}
```

import * as fs from "node:fs/promises";
import { dirname, join } from "node:path";
import { pathToFileURL } from "node:url";
import { parseArgs } from "node:util";
import { audioItems, ssmlDocument } from "@/lib/audio";
import type { Language } from "@/lib/levels";
import type { WordEntry } from "@/lib/words";

// 단어·예문·가나 음성을 Azure Speech(F0)로 만들어 public/audio/에 쓴다(spec/audio.md).
// manifest의 SSML 해시가 같고 파일이 있으면 건너뛰므로, 끊겨도 다시 돌리면 이어서 만들고 바뀐 것만 다시 만든다

const WORDS_DIR = "data/words";
const WORD_FILE = /^(en|ja)-[1-5]\.json$/;
export const MANIFEST_PATH = "data/audio-manifest.json";
// 바꾸면 SSML이 달라져 전부 다시 만든다(spec/audio.md "음성")
export const AZURE_VOICES: Record<Language, string> = { en: "en-US-AvaNeural", ja: "ja-JP-NanamiNeural" };
const OUTPUT_FORMAT = "audio-24khz-48kbitrate-mono-mp3";
const REQUEST_GAP_MS = 3_100; // F0는 분당 20회
const DEFAULT_RETRY_SECONDS = 60;
const MAX_429_IN_A_ROW = 5;
const USAGE = "사용법: npm run audio:generate [-- --ids <word_id 또는 가나>,...]";

export type Manifest = Record<string, string>;
export type PlannedAudio = { path: string; source: string; ssml: string; hash: string };

export function ssmlHash(ssml: string): string {
  return createHash("sha256").update(ssml).digest("hex").slice(0, 16);
}

export function plannedAudio(words: readonly WordEntry[]): PlannedAudio[] {
  return audioItems(words).map((item) => {
    const ssml = ssmlDocument(item.language, AZURE_VOICES[item.language], item.body);
    return { path: item.path, source: item.source, ssml, hash: ssmlHash(ssml) };
  });
}

export type GenerateAudioDeps = {
  args: string[];
  env: { key: string | undefined; region: string | undefined };
  readWords: () => Promise<WordEntry[]>;
  readManifest: () => Promise<Manifest>;
  writeManifest: (manifest: Manifest) => Promise<void>;
  audioExists: (path: string) => Promise<boolean>; // path는 "/audio/..."
  writeAudio: (path: string, bytes: Uint8Array) => Promise<void>;
  fetch: (url: string, init: RequestInit) => Promise<Response>;
  sleep: (ms: number) => Promise<void>;
  log: (line: string) => void;
};

function parseCliArgs(args: string[]): { ids: Set<string> | null } | null {
  try {
    const { values } = parseArgs({ args, options: { ids: { type: "string" } } });
    if (values.ids === undefined) return { ids: null };
    return { ids: new Set(values.ids.split(",").map((s) => s.trim()).filter((s) => s !== "")) };
  } catch {
    return null; // 모르는 옵션
  }
}

// 성공하면 mp3 바이트, 멈춰야 하면 null(이유는 로그)
async function synthesize(deps: GenerateAudioDeps, url: string, key: string, audio: PlannedAudio): Promise<Uint8Array | null> {
  for (let attempt = 1; ; attempt++) {
    const res = await deps.fetch(url, {
      method: "POST",
      headers: {
        "Ocp-Apim-Subscription-Key": key,
        "Content-Type": "application/ssml+xml",
        "X-Microsoft-OutputFormat": OUTPUT_FORMAT,
        "User-Agent": "langrow-generate-audio",
      },
      body: audio.ssml,
    });
    if (res.status === 429) {
      if (attempt >= MAX_429_IN_A_ROW) {
        deps.log(`${audio.path}: 429가 ${MAX_429_IN_A_ROW}번 이어져 멈춥니다`);
        return null;
      }
      const seconds = Number(res.headers.get("retry-after")) || DEFAULT_RETRY_SECONDS;
      deps.log(`429: ${seconds}초 기다렸다가 다시 보냅니다 (${audio.path})`);
      await deps.sleep(seconds * 1000);
      continue;
    }
    const bytes = new Uint8Array(await res.arrayBuffer());
    if (!res.ok || bytes.length === 0) {
      const detail = res.ok ? "빈 응답" : new TextDecoder().decode(bytes).slice(0, 200);
      deps.log(`${audio.path}: ${res.status} ${detail}`);
      return null;
    }
    return bytes;
  }
}

export async function main(deps: GenerateAudioDeps): Promise<number> {
  const parsed = parseCliArgs(deps.args);
  if (!parsed) {
    deps.log(USAGE);
    return 1;
  }
  const { key, region } = deps.env;
  if (!key || !region) {
    deps.log("AZURE_SPEECH_KEY·AZURE_SPEECH_REGION이 없습니다. .env.local에 넣고 다시 실행하세요");
    return 1;
  }

  const all = plannedAudio(await deps.readWords());
  const ids = parsed.ids;
  const targets = ids === null ? all : all.filter((a) => ids.has(a.source));
  if (ids !== null && targets.length === 0) {
    deps.log(`--ids에 맞는 항목이 없습니다: ${[...ids].join(", ")}`);
    return 1;
  }

  const manifest = await deps.readManifest();
  const url = `https://${region}.tts.speech.microsoft.com/cognitiveservices/v1`;
  let made = 0;
  let skipped = 0;
  let requested = false;
  for (const audio of targets) {
    if (manifest[audio.path] === audio.hash && (await deps.audioExists(audio.path))) {
      skipped++;
      continue;
    }
    if (requested) await deps.sleep(REQUEST_GAP_MS);
    requested = true;
    const bytes = await synthesize(deps, url, key, audio);
    if (bytes === null) {
      deps.log(`멈춤: ${made}개를 만든 뒤 실패했습니다. 다시 실행하면 이어서 만듭니다`);
      return 1;
    }
    // 파일마다 manifest를 써서 중간에 끊겨도 만든 것은 다시 만들지 않는다
    await deps.writeAudio(audio.path, bytes);
    manifest[audio.path] = audio.hash;
    await deps.writeManifest(manifest);
    made++;
    if (made % 100 === 0) deps.log(`${made}개 만듦 (${made + skipped} / ${targets.length})`);
  }
  deps.log(`완료: ${made}개 만듦, ${skipped}개 건너뜀`);
  return 0;
}

// ---- 실제 deps (파일, Azure). 테스트는 가짜 deps만 쓴다 ----

export async function readWordFiles(dir = WORDS_DIR): Promise<WordEntry[]> {
  const names = (await fs.readdir(dir)).filter((name) => WORD_FILE.test(name)).sort();
  const files = await Promise.all(names.map(async (name) => JSON.parse(await fs.readFile(join(dir, name), "utf8")) as WordEntry[]));
  return files.flat();
}

const publicFile = (path: string) => join("public", path);

// 키 순서를 고정해 diff를 작게 한다
function manifestJson(manifest: Manifest): string {
  const sorted = Object.fromEntries(Object.entries(manifest).sort(([a], [b]) => (a < b ? -1 : 1)));
  return `${JSON.stringify(sorted, null, 2)}\n`;
}

function realDeps(): GenerateAudioDeps {
  return {
    args: process.argv.slice(2),
    env: { key: process.env.AZURE_SPEECH_KEY, region: process.env.AZURE_SPEECH_REGION },
    readWords: () => readWordFiles(),
    readManifest: async () => {
      try {
        return JSON.parse(await fs.readFile(MANIFEST_PATH, "utf8")) as Manifest;
      } catch (error) {
        if ((error as NodeJS.ErrnoException).code === "ENOENT") return {};
        throw error;
      }
    },
    writeManifest: (manifest) => fs.writeFile(MANIFEST_PATH, manifestJson(manifest)),
    audioExists: (path) => fs.access(publicFile(path)).then(
      () => true,
      () => false,
    ),
    writeAudio: async (path, bytes) => {
      await fs.mkdir(dirname(publicFile(path)), { recursive: true });
      await fs.writeFile(publicFile(path), bytes);
    },
    fetch: (url, init) => fetch(url, init),
    sleep: (ms) => new Promise((resolve) => setTimeout(resolve, ms)),
    log: (line) => console.log(line),
  };
}

"use client";

import { CircleAlert, Snail, Volume2 } from "lucide-react";
import { useEffect, useRef, useState, useSyncExternalStore } from "react";
import { SLOW_RATE, pickVoice } from "@/lib/audio";
import { stripFurigana } from "@/lib/furigana";
import type { Language } from "@/lib/levels";

// [듣기]·[천천히 듣기](spec/audio.md "재생 규칙", ui.md "음성 재생"). 누를 때만 재생하고 페이지에서 소리는 하나만 낸다.
// 파일(단어·예문·가나)은 Audio로, 대화 문장은 브라우저 음성으로 읽는다. 학습 언어 음성이 없으면 대화 버튼을 그리지 않는다

export type SpeakSource = { kind: "file"; src: string } | { kind: "speech"; text: string; language: Language };
type Variant = "pill" | "compact";
type Align = "start" | "center";
type Props = { source: SpeakSource; variant?: Variant; align?: Align };
// 재생을 시작하고 멈추는 함수를 돌려준다. 실패는 onError로 알린다
type Play = (rate: number, onError: () => void) => () => void;

const FOCUS_RING = "focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-accent";
const PILL = `inline-flex h-9 items-center gap-1.5 rounded-full border border-line-input bg-card px-3 text-sm font-semibold text-ink hover:bg-hover ${FOCUS_RING}`;
const COMPACT = `inline-flex h-9 items-center gap-1 px-1 text-xs font-semibold text-accent ${FOCUS_RING}`;
const FAILED = "소리를 재생하지 못했어요. 다시 눌러 보세요.";

// 지금 나는 소리를 멈추는 함수. 다른 버튼을 누르면 먼저 부른다
let stopCurrent: (() => void) | null = null;

export function SpeakButtons({ source, variant = "pill", align = "start" }: Props) {
  if (source.kind === "speech") {
    return <SpeechButtons text={source.text} language={source.language} variant={variant} align={align} />;
  }
  const { src } = source;
  return <Buttons play={(rate, onError) => playFile(src, rate, onError)} variant={variant} align={align} />;
}

function playFile(src: string, rate: number, onError: () => void): () => void {
  let stopped = false;
  const audio = new Audio(src);
  audio.playbackRate = rate;
  // 우리가 멈춰서 거부된 play()(AbortError)는 오류가 아니다
  const fail = () => {
    if (!stopped) onError();
  };
  audio.addEventListener("error", fail);
  audio.play().catch(fail);
  return () => {
    stopped = true;
    audio.pause();
  };
}

function subscribeVoices(onChange: () => void): () => void {
  if (!("speechSynthesis" in window)) return () => {};
  window.speechSynthesis.addEventListener("voiceschanged", onChange);
  return () => window.speechSynthesis.removeEventListener("voiceschanged", onChange);
}

function SpeechButtons({ text, language, variant, align }: { text: string; language: Language; variant: Variant; align: Align }) {
  // 음성 목록은 늦게 올 수 있다(voiceschanged). 서버 렌더링 때는 그리지 않는다
  const voiceURI = useSyncExternalStore(
    subscribeVoices,
    () => ("speechSynthesis" in window ? (pickVoice(window.speechSynthesis.getVoices(), language)?.voiceURI ?? null) : null),
    () => null,
  );
  if (voiceURI === null) return null;

  const play: Play = (rate, onError) => {
    const synth = window.speechSynthesis;
    const voice = synth.getVoices().find((v) => v.voiceURI === voiceURI);
    if (voice === undefined) {
      onError();
      return () => {};
    }
    const utterance = new SpeechSynthesisUtterance(stripFurigana(text));
    utterance.voice = voice;
    utterance.lang = voice.lang;
    utterance.rate = rate;
    // 우리가 멈춰서 생긴 중단은 오류가 아니다
    utterance.onerror = (event) => {
      if (event.error !== "interrupted" && event.error !== "canceled") onError();
    };
    synth.cancel();
    synth.speak(utterance);
    return () => synth.cancel();
  };
  return <Buttons play={play} variant={variant} align={align} />;
}

function Buttons({ play, variant, align }: { play: Play; variant: Variant; align: Align }) {
  const [failed, setFailed] = useState(false);
  const stopRef = useRef<(() => void) | null>(null);

  // 버튼이 사라지면(카드를 뒤집거나 넘김, 화면 이동) 이 버튼의 소리를 멈춘다
  useEffect(
    () => () => {
      const stop = stopRef.current;
      if (stop !== null && stopCurrent === stop) {
        stop();
        stopCurrent = null;
      }
    },
    [],
  );

  function start(rate: number) {
    stopCurrent?.();
    setFailed(false);
    const stop = play(rate, () => setFailed(true));
    stopRef.current = stop;
    stopCurrent = stop;
  }

  const compact = variant === "compact";
  const button = compact ? COMPACT : PILL;
  const iconSize = compact ? 14 : 16;
  return (
    <div className={`flex flex-col gap-1 ${align === "center" ? "items-center" : "items-start"}`}>
      <div className={`flex ${compact ? "gap-3" : "gap-2"}`}>
        <button type="button" onClick={() => start(1)} className={button}>
          <Volume2 size={iconSize} aria-hidden="true" className="text-accent" />
          듣기
        </button>
        <button type="button" onClick={() => start(SLOW_RATE)} className={button}>
          <Snail size={iconSize} aria-hidden="true" className="text-accent" />
          천천히 듣기
        </button>
      </div>
      {failed && (
        <p role="alert" className="flex items-center gap-1 text-sm text-danger">
          <CircleAlert size={16} aria-hidden="true" className="shrink-0" />
          {FAILED}
        </p>
      )}
    </div>
  );
}
