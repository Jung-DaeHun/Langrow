# UI 디자인 가이드

- 요약 규칙이다. 토큰 값, 컴포넌트 클래스, 화면별 구성은 `docs/spec/ui.md`에 있다. 화면·컴포넌트를 구현하는 step은 그 문서를 읽는다.
- 시각 기준은 Langrow 디자인 프로토타입(크림 배경 + 초록 4단계, 저장소 밖)이고, 원칙 기준은 [Figma UI 디자인 원칙 7가지](https://www.figma.com/ko-kr/resource-library/ui-design-principles/)다.
- 화면 동작(상태 전이, 한도, 에러 코드)은 `docs/spec/plan.md`를 따른다. 라이트 모드만 지원한다.

## 디자인 원칙
1. **매일 쓰는 학습 도구다.** 마케팅 페이지가 아니다. 홈은 "오늘 할 일"과 진행률부터 보여 준다.
2. **한 화면에 주된 행동은 하나다.** primary 버튼은 화면마다 1개다. 회차·대화·테스트 중(집중 모드)에는 탭바를 숨긴다.
3. **따뜻하고 차분하게 고친다.** 교정은 빨강이 아니라 민트 카드로 "이렇게 말하면 더 자연스러워요"라고 보여 준다. 빨강은 오답·전송 실패·입력 오류에만 쓴다.

## Figma 원칙 적용
- **계층 구조**: 화면 제목(`text-h1`, `brand`)은 화면마다 1개다. 단계는 크기·굵기·색 중 2가지 이상을 바꿔 나눈다.
- **점진적 공개**: 여러 단계로 된 흐름(온보딩, 플래시카드 → 빈칸 → 결과, 레벨업 20문제)은 진행 바와 `i / n`을 함께 보여 준다. 중급 이상의 번역은 탭해서 펼친다.
- **일관성**: 같은 역할에는 `docs/spec/ui.md`의 컴포넌트만 쓴다. 새 패턴은 그 문서에 이유와 함께 추가한다.
- **대비**: 주된 행동은 초록 filled, 보조는 outline, 실패는 빨강, 보상은 골드다. 한 영역에 강조색은 하나만 쓴다.
- **접근성**: WCAG 2.1 AA를 지킨다(아래 "접근성").
- **근접성**: 간격은 카드 안 8–16px, 카드 사이 16–24px, 섹션 사이 32px이다. 되돌릴 수 없는 동작은 주된 행동과 떨어뜨린다([대화 끝내기]는 오른쪽 위, 전송은 오른쪽 아래).
- **정렬**: 기본은 왼쪽 정렬이다(랜딩 포함). 가운데 정렬은 플래시카드와 로딩 표시에만 쓴다.

## AI 슬롭 안티패턴 — 하지 마라
| 금지 사항 | 이유 |
|-----------|------|
| backdrop-filter: blur() | glass morphism은 AI 템플릿의 가장 흔한 징후 |
| gradient-text, 배경·버튼 그라데이션, 질감, 패턴 | 면은 단색으로 칠한다. 예외는 진행 링의 `conic-gradient`(데이터 표시) |
| "Powered by AI" 배지, ✨·로봇 아이콘 | 기능이 아니라 장식이다 |
| box-shadow 글로우 애니메이션 | 네온 글로우는 AI 슬롭이다 |
| 보라/인디고 브랜드 색상 | "AI = 보라색" 클리셰. 브랜드는 초록이다 |
| 역할과 상관없이 모든 요소에 같은 rounded-2xl | 모서리는 역할별로 다르다 |
| 배경 gradient orb (blur-3xl 원형) | 모든 AI 랜딩 페이지에 있는 장식 |
| 카드에 테두리 + 그림자, 색 있는 왼쪽 테두리 | 카드는 그림자만 쓴다. 선은 목록·표 구분선에만 |
| 순수 흰색 페이지 배경 | 페이지는 크림(`bg-page`), 흰색은 카드에만 |
| UI 텍스트·버튼의 이모지 | spec의 🔥 같은 표기는 Lucide 아이콘으로 그린다 |
| 장식용 반복 애니메이션(pulse, bounce, shimmer) | 반복은 AI 응답 대기 점 3개만 허용 |

## 색상
`@theme` 토큰만 쓴다. hex 직접 입력과 Tailwind 기본 팔레트는 쓰지 않는다. 값은 `docs/spec/ui.md`에 있다.

| 토큰 | 역할 |
|---|---|
| `page` | 페이지 배경(크림), 상단바 |
| `card` | 카드·목록·시트·모달·탭바·AI 말풍선(흰색) |
| `zone` / `hover` | 진행 바 트랙·세그먼트 배경·비활성 / 행 hover |
| `house` / `uplift` | 진한 초록 밴드·푸터·내 말풍선·토스트 / 그 위 보조 면. 글자는 `white`·`white/70` |
| `mint` / `ok-wash` | 선택·완료·교정 카드·성공 안내 / 선택된 타일·정답 보기 배경 |
| `brand` | 화면 제목, 워드마크, 학습 단어, 교정된 문장 |
| `accent` | primary 버튼, 링크, 아이콘, 진행 바 채움 |
| `ink` / `ink-muted` | 본문 / 보조 문구 |
| `line` / `line-input` | 목록·표 구분선 / pill 버튼·입력 테두리 |
| `danger` / `danger-wash` | 오답·전송 실패·300자 초과·남은 사용량 0 / 오답 보기 배경 |
| `gold` `gold-light` `gold-wash` `on-gold` | 연속 학습일, Pro·체험, 한도 도달 체험 안내, 레벨업 합격 |

- 빨강은 교정에 쓰지 않는다. 노랑 경고색은 쓰지 않는다.
- `gold`는 글자색으로 쓰지 않는다(대비 2.2:1). 골드 면 위 글자는 `on-gold`로 쓰고, 골드 아이콘 옆에는 항상 글자를 둔다.

## 타이포그래피
- 폰트는 Pretendard Variable(UI 전체)과 Noto Sans JP(`lang="ja"` 텍스트만)다. 디자인 시스템의 Manrope·Lora·Kalam은 한글이 없어서 쓰지 않는다.
- 크기는 토큰 클래스만 쓴다: `text-display`(랜딩 히어로), `text-h1`(화면 제목), `text-h3`(섹션), `text-lead`(카드 제목·퀴즈 보기), `text-base`(본문·말풍선·입력), `text-sm`(보조), `text-micro`(메타), `text-xs`(탭·태그), `text-quiz`·`text-word`·`text-kana`(학습 콘텐츠).
- 줄바꿈은 `word-break: keep-all`, 바뀌는 숫자는 `tabular-nums`로 둔다. 입력 글자는 16px 이상이다.
- 후리가나는 React `<ruby>` 요소로 그린다. 표시 레벨은 spec 2장을 따른다.

## 레이아웃
- 모바일 우선이다. 간격은 Tailwind 기본 스케일만 쓰고 `gap-[13px]` 같은 임의값을 쓰지 않는다. 좌우 여백은 `px-4`, `lg` 이상 `px-10`이다.
- 최대 너비: 앱 본문 720(`max-w-app`), 공개 페이지 1040, 온보딩 520, 약관 680.
- 셸: 모바일은 상단바(워드마크 또는 뒤로 pill + 언어·레벨 pill + 연속일 칩)와 하단 탭 4개(홈·대화·단어·계정)다. `lg` 이상은 왼쪽 사이드바(레벨업 테스트·가나 익히기 포함, 아래에 남은 사용량)로 바꾼다.
- 집중 모드(대화방, 종료 피드백, 단어 회차, 레벨업 진행, 가나 카드)에서는 탭바를 숨기고 왼쪽 위에 뒤로 pill을 둔다.
- 모서리는 버튼·칩 `rounded-full`, 카드류 `rounded-xl`, 말풍선 18px, 텍스트 입력 4px이다.

## 컴포넌트와 화면 규칙
- 컴포넌트: 버튼(Primary·Outline·Dark-outline·Pill·Google), 카드(기본·보상·밴드), 목록 묶음, 선택 타일, 태그·연속일 칩, 안내(정보·성공·보상·오류), 진행 바·링, 세그먼트, 바텀시트, 모달, 토스트, 대화 입력창, 말풍선, 플래시카드, 빈칸 퀴즈, 사용량, 한도 안내, 플랜 카드. 클래스는 `docs/spec/ui.md`에 있다.
- primary 버튼 높이는 44px, 보조는 36px다. 라벨은 동사로 끝낸다(시작하기, 다음 문제, 다시 보내기).
- 에러는 토스트가 아니라 그 자리의 오류 안내로 보여 주고, 문구는 서버 `message`를 쓴다. 토스트는 짧은 성공 확인에만 쓴다.
- AI 응답 대기·채점 중 표시는 점 3개 하나로 통일한다(스피너·스켈레톤 없음).
- 기준 변형: 홈 A(카드), 랜딩 A(분할), 단어 플래시카드, 계정 플랜 카드.

**학습 화면 (spec 반영, 프로토타입과 다른 부분 포함)**
- 번역은 입문·초보면 기본으로 펼치고, 중급 이상이면 말풍선을 탭해서 펼친다.
- 교정은 내 말풍선 바로 아래 민트 카드로 항상 보여 준다. `correction`이 `null`이면 아무것도 표시하지 않는다.
- 대화 입력은 서버의 429 뒤에만 막는다. 표시된 남은 사용량만 보고 막지 않는다. 전송 실패(503)면 입력을 지우지 않고 [다시 보내기]를 둔다.
- 플래시카드 버튼은 [모르겠어요]/[알아요]다. 오답 복습은 플래시카드만 한다.
- 빈칸 퀴즈는 단어 학습이면 바로 정답을 보여 주고, 레벨업 테스트면 정답을 보여 주지 않는다.
- 레벨 내리기는 상단 언어·레벨 시트에서 한다.

## 아이콘·애니메이션
- 아이콘은 `lucide-react`, 기본 20px, `strokeWidth` 2다. 원형 배경은 목록 행과 선택 타일의 앞 아이콘에만 쓴다.
- 허용 애니메이션: 버튼 hover·press(200ms, `scale-95`), 화면 진입 fade(250ms), 바텀시트(300ms), 플래시카드 뒤집기(450ms), 진행 바(400ms), 체크박스 스프링, 응답 대기 점 3개(유일한 반복). 그 밖의 애니메이션은 쓰지 않는다.
- `prefers-reduced-motion: reduce`이면 모두 즉시 바꾼다.

## 문구
- 해요체로 짧게 쓰고 권유형("~해 보세요")을 쓴다. 명령조·과장·느낌표 남발은 쓰지 않는다.
- 숫자는 구체적으로 쓰고 분수는 `n / m`으로 쓴다. 예: "20문제 중 16개".
- 실수는 부드럽게 말한다: "오답이에요. 정답은 …", "이번엔 아쉽게 통과하지 못했어요".
- 돈 얘기는 사실만 쓴다: "결제 정보는 받지 않아요", "자동 결제는 없어요".
- AI를 내세우지 않는다. 국외 이전 고지에는 Anthropic을 사실대로 적는다.
- 고유명사는 영문 그대로 쓴다: Langrow, Free, Pro, Google. 워드마크는 텍스트 "Langrow"(800, 자간 -0.03em, `brand`, 어두운 면 위에서는 흰색)로 쓰고, 로고 파일이 생기면 바꾼다.

## 접근성
- `<html lang="ko">`로 두고, 학습 언어로 된 텍스트(말풍선, 교정, 단어, 보기, 가나)에 `lang="en"` 또는 `lang="ja"`를 단다.
- 대비는 AA(텍스트 4.5:1, 아이콘 3:1) 이상이다. 터치 영역은 44px(보조 36px) 이상이다.
- 상호작용 요소는 `<button>`·`<a>`로만 만들고(`div onClick` 금지), 포커스는 `focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-accent`로 보인다. 시트·모달은 포커스를 가두고, Esc로 닫고, 닫으면 포커스를 돌려준다.
- 새 메시지는 `aria-live="polite"`, 토스트는 `role="status"`, 오류는 `role="alert"`로 알린다. 아이콘만 있는 버튼에는 `aria-label`을 단다.
- 색만으로 상태를 전하지 않는다(정답·오답은 아이콘 + 문구). 200% 확대에서도 가로 스크롤이 없어야 한다.
