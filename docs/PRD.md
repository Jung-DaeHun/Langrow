# PRD: Langrow (가칭)

## 목표
한국인 학습자가 하루 15분, 상황 롤플레이 AI 대화와 단어 학습으로 영어·일본어를 익히게 한다. MVP의 목적은 **수요 검증**이다: 사람들이 반복해서 쓰는지, Pro를 원하는지 측정한다.

원칙: 수요 검증에 필요 없는 것, 또는 없어도 사용자가 불편하지 않은 것은 만들지 않는다.

## 사용자
- **민지 (28, 직장인)**: 영어 회화를 다시 시작하는 중급 학습자. 출퇴근 15분 동안 모바일로 학습한다.
- **준호 (21, 대학생)**: 일본 여행을 앞두고 일본어를 처음 배우는 입문자. 히라가나는 일부만 읽는다.
- 만 14세 이상, 구글 로그인만, UI는 한국어만.

## 핵심 기능
1. **상황 롤플레이 AI 대화**: 레벨당 상황 4개(총 20개). 사람이 검수한 고정 첫 마디로 시작하고, 사용자 발화마다 AI 응답 + 한국어 번역 + 교정을 보여 준다. 세션은 최대 20턴, 입력은 1~300자. 끝내면 잘한 점·고칠 점 피드백을 준다. 모든 레벨에서 한국어로 입력하면 학습 언어로 옮긴 문장("이렇게 말하면 돼요")을 보여 주고, 대화방 맨 위 안내 줄로 이를 알린다. 일본어는 모든 레벨에서 한자·가타카나 위에 히라가나 읽기를 단다(단어·레벨업 테스트도 같다). AI 말풍선과 교정 문장은 [문장 뜯어보기]로 열면 의미 조각마다 한국어 뜻을 보여 준다(AI가 턴마다 함께 만든다).
2. **단어**: 언어 × 레벨마다 200개(미리 생성·검수). 회차는 최대 10개: 플래시카드 → 4지선다 빈칸 → 회차 끝에 한 번 저장. 틀린 단어는 오답 복습으로 다시 본다. 빈칸 채점 뒤와 복습 카드 뒷면에서 정답이 왜 맞는지 AI 설명을 요청할 수 있다(단어·보기 조합마다 처음 요청 때 만들어 저장하고 재사용).
3. **레벨업 테스트**: 레벨 1~4에서 현재 레벨 단어 20문제(빈칸). 서버가 채점하고 16개 이상이면 레벨 +1. 재응시 제한 없음.
4. **가나 익히기**: 일본어 입문·초보용. 히라가나/가타카나 각 71자 플래시카드. AI·DB를 쓰지 않는다.
5. **레벨**: 입문(1)·초보(2)·중급(3)·상급(4)·고수(5), 언어별로 저장. 처음에만 직접 고르고, 올리기는 테스트로만, 내리기는 자유.
6. **홈**: 오늘 할 일 2개(새 단어 10개, 유효한 대화 세션 1개), 연속 학습일, 이어서 대화하기, 오답 복습, 레벨업 테스트, 가나 익히기, 남은 사용량.
7. **일본어 한글 발음**: 입문~중급에서 대화 말풍선(첫 마디 포함)·교정 문장, 단어 카드(단어·예문), 빈칸 채점 뒤 예문 아래에 한글 발음(예: 今日は → 쿄-와)을 보여 준다. 중급 말풍선은 번역과 함께 펼친다. 조사 は·へ와 장음을 맞게 쓰려고 AI가 만든다: 대화는 턴마다 응답에 함께, 단어는 미리 만들어 저장한다.
8. **음성**: 단어·예문·가나는 미리 만든 여성 합성 음성(Azure, 저장소에 mp3 커밋. 남성 음성 선택은 나중에)으로, 대화 문장(AI 말풍선·교정)은 브라우저 음성으로 [듣기]·[천천히 듣기](0.75배)를 제공한다. 누를 때만 재생하고, 빈칸은 채점 뒤에만, 레벨업 테스트에는 두지 않는다. 사용량에 세지 않고 비용은 0원이다.
9. **플랜**: Free/Pro를 하루 사용량으로 구분한다. 결제는 없고, [7일 무료 체험]은 계정당 1번이다. 체험이 끝난 뒤 Pro 버튼은 "정식 출시 준비 중"을 보여 준다.

| | Free | Pro |
|---|---|---|
| AI 대화 턴 | 하루 20 | 하루 150 |
| 새 단어 | 하루 10 | 하루 30 |
| AI 정답 설명 | 하루 10 | 무제한 |
| 표시 가격 | 무료 | 월 9,900원 |

- 한도는 계정 단위(언어 합산), 한국 자정 기준이다. 종료 피드백·복습·빈칸·레벨업 테스트·가나는 세지 않는다. AI 정답 설명만 따로 세며, 설명 한도 도달은 체험 전환 지표에 넣지 않는다.
- **유효한 대화 세션** = 성공한 턴이 3개 이상인 세션. [대화 끝내기]를 눌렀는지와 무관하다.
- **연속 학습일**: 대화 턴 성공, 신규 단어 저장, 복습, 가나 회차 완료, 레벨업 테스트 제출로 갱신한다. 언어와 무관하게 하나로 센다.

## 수요 검증 지표 (첫 실험)
- 출시 후 28일 동안 모집하며 목표는 온보딩 완료 50명이다. 각 사용자를 온보딩 후 28일 관찰하고, 운영·테스트 계정은 제외한다. 비율에는 항상 분자/분모를 붙인다.

| 지표 | 판단 기준 |
|---|---|
| 온보딩 완료율 (가입 후 24시간 안) | 60% 이상 |
| 첫 세션 완료율 (온보딩 후 24시간 안에 유효한 대화 세션) | 50% 이상 |
| D1 / D7 학습 재참여율 | 30% / 15% 이상 |
| 목표 완료·한도 도달 → 체험 (온보딩 후 7일 안에 첫 도달, 도달 후 7일 안에 체험 시작. `feature`별로도 보고) | 분모 20명 이상에서 20% 이상 |
| 체험 후 Pro 클릭 (참고 지표) | 기준 없음, 분자/분모만 보고 |

- Free 단어 한도는 오늘 목표와 같으므로, 단어 한도 도달은 "추가 학습 의도"가 아니라 "목표 완료"로 해석한다.
- 지표는 로컬 `scripts/metrics-report.ts`로 계산한다. 방문 추적과 대시보드는 만들지 않는다.
- 무료 체험·Pro 클릭은 구매 의향의 간접 지표다. 기준은 관찰 전에 고정하고 소급 변경하지 않는다.

## MVP 제외 사항
- 실제 결제·구독 관리, 카카오·이메일 로그인, 관리자 페이지
- STT(발음 평가), 음성 자동 재생, SRS, 자유 대화, 첫 레벨 배치 테스트, 레벨업 회화 시험
- 영어·일본어 외 언어(언어를 나중에 추가할 수 있는 구조로는 만든다), 한국어 외 UI, 네이티브 앱, 알림·이메일
- 응답 스트리밍, 메시지 멱등 키, 정리용 cron, 유휴 세션 자동 종료, 단어 회차 이어하기
- 방문 추적, 체험 종료 예고 배너, AI 레벨 조정 제안, 빈칸 직접 입력, 종료 피드백 재생성

## 출시 최소 요건
- 개인정보처리방침(국외 이전: Anthropic(미국)으로 대화 전송, Vercel·Supabase 고지)과 이용약관(만 14세 이상). 온보딩 필수 체크 1개로 동의를 받는다.
- 합성 음성 고지(Azure 이용 규정): `/words`·`/kana` 안내 문구에 "발음은 합성 음성이에요", 문제 신고는 약관의 문의 이메일.
- 구글 OAuth 동의 화면 게시. 회원 탈퇴는 이메일 문의 → Supabase 대시보드에서 삭제(FK cascade).
- Anthropic 지출 한도·알림, 배포 전 `supabase db dump`.
